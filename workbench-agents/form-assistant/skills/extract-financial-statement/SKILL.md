# 财报数据提取

1. 仅处理用户明确上传到当前辅助任务的文件。
2. 通过工作台提供的上传动作接收文件；当前验证版本以工作台后端返回的结构化 mock 提取结果为准。
3. 至少保留报告期、营业收入、净利润、资产总额、负债总额及资产负债率；标明来源文件和报告期。
4. 无法识别或字段缺失时明确返回缺失项，不补造数字。
5. 把提取结果保存到当前调查报告任务上下文，使同一报告的后续模块可复用，不重复要求上传。
